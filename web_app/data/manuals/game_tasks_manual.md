# 數位財務管理系統 - 任務與等級系統手冊

Q: 系統的等級 (Level) 與經驗值 (XP) 怎麼計算？最高可以幾等？
A: 系統最高等級上限為 100 等。升級所需的 XP 採階梯式成長：
* 1~9 等：100 + (目前等級 x 20)
* 10~19 等：300 + (目前等級 x 30)
* 20~49 等：1000 + (目前等級 x 50)
* 50~99 等：3000 + (目前等級 x 100)
* 100 等以上：固定 10000 XP
當獲得的 XP 超過升級門檻時，多餘的 XP 會自動保留並累加到下一個等級，支援連續跳級。

Q: 每日的「結算型任務 (Nightly Tasks)」有哪些？達成條件是什麼？
A: 結算型任務會在每天結束時（或手動觸發時）檢查當日總花費：
1. 【預算控制】：當日「總支出」必須 <= 500 元。
2. 【節能減碳】：當日「交通」類別支出必須 <= 100 元。
3. 【減少外食】：當日「飲食」類別支出必須 <= 300 元。
4. 【無現金支付】：當日所有支出紀錄都必須使用「信用卡 (credit)」帳戶。
5. 【極限的挑戰】：當日「總支出」加總 <= 100 元。

Q: 記帳時，如何觸發「行為與條件任務」？
A: 只要在記帳時符合特定條件，系統會即時增加任務進度：
* 【大額支出】：單筆支出金額 >= 1000 元。
* 【大膽消費】：單筆支出金額 > 2000 元。
* 【深度思考】：記帳備註字數超過 100 個字。
* 【自我投資】：新增一筆「學習」類別的支出。
* 【享受當下】：新增一筆「娛樂」類別的支出。
* 【意外之財】：獲得非固定薪水（排除工資、薪資、獎金、投資）的收入。
* 【客製分類】：使用預設（需要、想要、旅遊）以外的自訂標籤。
* 【雙向標籤】：一筆紀錄同時使用 2 個以上的標籤，且至少包含 1 個自訂標籤。
* 【零錢存錢】：進行「轉帳」或紀錄一筆「收入」。
* 【資金調度】：進行一次「轉帳」操作。

Q: 特殊卡牌對應的專屬任務是什麼？
A:
* 【工作紀錄】(SJ任務)：新增一筆「工作」類別的紀錄。
* 【人際開銷】(SJ任務)：新增一筆「社交」類別的紀錄。
* 【宏觀分析】(NF任務)：匯出年度報表。
* 【智慧的洞察】(NT稀有任務)：在與 AI 聊天時，訊息中提到「CPI」，並且包含「最高」或「指標」等關鍵字。
